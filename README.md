# 🧠 Interview Catalog

> A structured engineering knowledge repository for mastering software engineering interview topics through concepts, visuals, interview-focused Q&A, and production-inspired implementations.

---

## 👋 About This Repository

Interview Catalog is a personal study repository built to prepare for Software Engineer and Backend Engineer interviews at product-based companies.

Instead of collecting random notes, this repository organizes every topic into a consistent learning framework:

* Understand the concept
* Learn interview expectations
* Build working implementations
* Revisit with visual explanations

The goal is not memorization.

The goal is developing engineering intuition that can be applied during interviews and real-world development.

# 🎯 Learning Framework

Every topic follows the same learning process.

## Phase 1 — Concepts

Build a strong understanding of the fundamentals.

Includes:

* Plain-English explanations
* Visual diagrams
* Architecture breakdowns
* Trade-off analysis
* Real-world examples

---

## Phase 2 — Interview Preparation

Prepare for technical interviews.

Includes:

* Easy Questions
* Medium Questions
* Advanced Questions
* Follow-up Questions
* Real Interview Scenarios

---

## Phase 3 — Implementations

Convert theory into practice.

Includes:

* Working code examples
* Production-inspired solutions
* Common interview coding problems
* Well-commented implementations
